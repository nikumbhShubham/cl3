HADOOP ON UBUNTU: STEP-BY-STEP (FOR P3 & P10)
--------------------------------------------------------------------------------
1. START HADOOP (Type these one by one):
   $ start-dfs.sh
   $ start-yarn.sh

2. VERIFY (Type 'jps'):
   $ jps
   (Ensure you see: NameNode, DataNode, ResourceManager, NodeManager)

3. THE STREAMING JAR (The "Obvious" Path):
   In most Ubuntu labs, the JAR is located exactly here:
   /usr/local/hadoop/share/hadoop/tools/lib/hadoop-streaming-3.3.1.jar
   (Note: If your version is different, e.g., 3.2.1, change the number)

4. RUNNING A JOB (The "Recipe"):
   Step A: Upload your input file to Hadoop's memory:
   $ hadoop fs -put weather_data.txt /

   Step B: Run the MapReduce (Copy and paste this long command):
   $ hadoop jar /usr/local/hadoop/share/hadoop/tools/lib/hadoop-streaming-3.3.1.jar \
     -file weather_mapper.py -mapper "python3 weather_mapper.py" \
     -file weather_reducer.py -reducer "python3 weather_reducer.py" \
     -input /weather_data.txt \
     -output /weather_output

   Step C: View the final answer:
   $ hadoop fs -cat /weather_output/part-00000
